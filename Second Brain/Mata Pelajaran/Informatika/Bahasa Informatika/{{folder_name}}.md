- **Bahasa Imperatif / Prosedural (_Imperative / Procedural Languages_)**
    
    - **Penjelasan**: Bahasa yang fokus memberi tahu komputer **bagaimana** (_how_) menjalankan perintah langkah demi langkah (_step-by-step_).
        
    - **Contoh**: C, Pascal, Go.
        
- **Bahasa Berorientasi Objek / OOP (_Object-Oriented Programming Languages_)**
    
    - **Penjelasan**: Bahasa yang mengorganisir logika program ke dalam bentuk "Objek" yang memiliki data (_property_) dan perilaku (_method_).
        
    - **Contoh**: Java, C++, C#.
        
- **Bahasa Fungsional (_Functional Programming Languages_)**
    
    - **Penjelasan**: Bahasa yang membangun program menggunakan fungsi-fungsi matematika murni tanpa mengubah status data global (_immutable state_).
        
    - **Contoh**: Haskell, Elixir, Erlang.
        
- **Bahasa Skrip (_Scripting Languages_)**
    
    - **Penjelasan**: Bahasa yang digunakan untuk mengotomatisasi tugas-tugas tertentu dan biasanya dieksekusi langsung oleh penerjemah (_interpreter_) tanpa perlu proses kompilasi manual.
        
    - **Contoh**: Python, JavaScript, Bash, PHP.
        
- **Bahasa Pertukaran Data (_Data Interchange / Serialization Languages_)**
    
    - **Penjelasan**: Bahasa yang tidak memiliki logika pemrosesan, melainkan khusus digunakan untuk menyusun, mengemas, dan mentransfer data antar aplikasi/server.
        
    - **Contoh**: JSON, XML, YAML.
        
- **Bahasa Tingkat Rendah (_Low-Level & Assembly Languages_)**
    
    - **Penjelasan**: Bahasa yang strukturnya sangat dekat dengan perintah mesin dan perangkat keras (_hardware_) komputer.
        
    - **Contoh**: Assembly, Machine Code.
