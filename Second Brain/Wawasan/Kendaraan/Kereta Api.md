# Kereta Api

Kereta api adalah kendaraan yang bergerak di atas rel (jalur khusus) dan merupakan salah satu alat transportasi darat paling efisien untuk perjalanan jarak jauh dan angkutan massal.

## Sejarah

### Era Uap (1800-an)
- **1804** — **Richard Trevithick** (Inggris) membangun lokomotif uap pertama yang beroperasi di rel di Merthyr Tydfil, Wales.
- **1825** — **Stockton and Darlington Railway** dibuka di Inggris, jalur kereta api komersial pertama di dunia.
- **1830** — **Liverpool and Manchester Railway** dibuka, jalur kereta api penumpang pertama yang melayani jadwal reguler.
- **1830-an–1860-an** — Kereta api menyebar ke seluruh Eropa, Amerika, dan Asia.

### Kereta Api di Indonesia
- **1864** — Nederlandsch-Indische Spoorweg Maatschappij (NISM) membangun jalur kereta api pertama di Indonesia: Batavia–Buitenzorg (Jakarta–Bogor).
- **1942** — Selama pendudukan Jepang, jalur kereta api diperluas untuk kepentingan militer.
- **1945** — Kemerdekaan Indonesia, perkeretaapian dinasionalisasi menjadi **PNKA** (1963).
- **1971** — PNKA berganti nama menjadi **PJKA**.
- **1991** — PJKA menjadi **PT Kereta Api Indonesia (Persero)**.
- **2010-an–sekarang** — Modernisasi: KRL Commuter Line, MRT Jakarta, KCIC (Whoosh), kereta bandara.

### Era Diesel & Elektrik (1950-an–1980-an)
- **1950-an** — Lokomotif diesel mulai menggantikan uap di banyak negara.
- **1964** — **Shinkansen** (Jepang) diluncurkan, kereta cepat pertama di dunia (kecepatan 210 km/jam).
- **1981** — **TGV** (Prancis) mulai beroperasi (kecepatan 260 km/jam).

### Era Kecepatan Tinggi (1990-an–sekarang)
- **2004** — **CRH** (Tiongkok) memulai era kereta cepat Tiongkok.
- **2007** — TGV memecahkan rekor kecepatan: **574,8 km/jam**.
- **2011** — **Shanghai Maglev** mencapai **431 km/jam** secara komersial.
- **2023** — **Whoosh (KCIC)** — Kereta cepat pertama di Asia Tenggara: Jakarta–Bandung dalam 40 menit.

## Tipe-Tipe Kereta Api

### Berdasarkan Jalur
| Tipe | Keterangan | Contoh di Indonesia |
| --- | --- | --- |
| Kereta Bandara | Menghubungkan bandara dengan kota | KA Soekarno-Hatta (Railink) |
| KRL Commuter | Kereta commuter untuk perjalanan dalam kota | KRL Commuter Line Jabodetabek |
| Kereta Antarkota | Perjalanan antar kota/kabupaten | KA Lokal, KA Prambanan |
| Kereta Cepat | Kecepatan 250+ km/jam | Whoosh KCIC Jakarta–Bandung |
| Kereta Luar Biasa (EKSP) | Kereta eksekutif/pariwisata jarak jauh | KA Argo, Gajayana, Taksaka |
| Locomotive-hauled | Lokomotif menarik gerbong | KA Barang, KA Penumpang klasik |
| Light Rail / Tram | Kereta ringan di kota | LRT Palembang, LRT Jabodebek |

### Berdasarkan Lokomotif
- **Lokomotif Uap** — Tekanan air panas/steam. Sudah tidak beroperasi komersial.
- **Lokomotif Diesel** — Mesin diesel. Paling banyak digunakan di Indonesia.
- **Lokomotif Elektrik (Listrik)** — Menggunakan listrik dari overhead line. KRL, MRT.
- **Kereta Rel Elektrik (KRE)** — Kereta mandiri (tanpa lokomotif terpisah) bertenaga listrik.

## Operator Kereta Api di Dunia

### Asia
- **JR Group** (Jepang) — Pionir kereta cepat Shinkansen.
- **CRRC** (Tiongkok) — Pabrikan kereta api terbesar di dunia.
- **Korail** (Korea Selatan) — KTX, SRT, ITX.
- **PT Kereta Api Indonesia** — Operator utama kereta api di Indonesia.
- **MRT Corp** (Malaysia) — MRT dan LRT Kuala Lumpur.
- **SMRT / SBS Transit** (Singapura) — MRT dan LRT.

### Eropa
- **SNCF** (Prancis) — TGV, TER, Intercités.
- **Deutsche Bahn** (Jerman) — ICE, regional trains.
- **Trenitalia** (Italia) — Frecciarossa, Italo.
- **Renfe** (Spanyol) — AVE.
- **Eurostar** — Kereta cepat London–Paris/Brussels.

### Amerika
- **Amtrak** (AS) — Operator utama kereta api penumpang.
- **Via Rail** (Kanada) — Kereta antarkota.

## Kereta Api di Indonesia

### PT KAI (Persero)
- Melayani: kota di Jawa dan Sumatera.
- Rute terpopuler: Jakarta–Bandung, Jakarta–Surabaya, Jakarta–Semarang.
- Kelas: Ekonomi, Bisnis, Eksekutif, Luxury.
- KRL Commuter Line melayani sekitar 1 juta penumpang/hari di Jabodetabek.

### Kereta Cepat Whoosh (KCIC)
- **Jakarta–Bandung** dalam **~40 menit**.
- Beroperasi mulai **Oktober 2023**.
- Kecepatan operasional: **350 km/jam**.
- Teknologi dari CRRC (Tiongkok).

### MRT Jakarta
- Fase 1: Lebak Bulus–Bundaran HI (16 km).
- Fase 2: Bundaran HI–Kemayoran (sedang dibangun).

## Fakta Menarik
- **Shinkansen** (Jepang) belum pernah mengalami kecelakaan fatal sejak beroperasi pada tahun 1964.
- **Trans-Siberian Railway** adalah jalur kereta api terpanjang di dunia: **9.289 km** dari Moskow ke Vladivostok.
- Kereta api Indonesia mengangkut sekitar **400+ juta penumpang per tahun** (2023).
- Rekor kecepatan kereta-api konvensional: **574,8 km/jam** oleh TGV V150 (Prancis, 2007).
